# Port Scanner by Vlanter

Простой и эффективный сканер TCP-портов, написанный на Python. 
Создан в учебных целях для понимания работы сетевых сокетов и протокола TCP.

## 🚀 Возможности
- Сканирование заданного диапазона портов.
- Поддержка как IP-адресов, так и доменных имен (благодаря `socket.gethostbyname`).
- Обработка сетевых ошибок и таймаутов для стабильной работы.

## 🛠️ Как запустить
1. Убедитесь, что у вас установлен Python 3.x.
2. Запустите скрипт в терминале:
   ```bash
   python port_scanner.py
